#  TECHNOVA 2026 - College Event Management System

##  Project Overview

TECHNOVA 2026 is a responsive College Event Management Portal developed using HTML, CSS, Bootstrap, and JavaScript. The website provides students with a platform to explore upcoming events, view event galleries, register for events, and contact organizers.

The project is designed to simplify event participation and improve communication between organizers and students. Similar college event portals typically focus on event discovery, registration, and showcasing past events.
